# 节点控件皮肤三档范围

## 已确认的需求

- 「只我们插件」是分发源码与首次安装的默认值。
- 「适配第三方」包含本插件、配套依赖包与其余节点的标准单行画布控件。
- 「所有都关闭」让标准控件调用其原始绘制函数，专用自绘控件保留交互、使用宿主基础颜色且移除胶囊投影。
- 本机开发通过 ComfyUI 用户区设置选中「适配第三方」，不改源码默认值，不根据 localhost 或 Git 目录猜测开发环境。
- 用户选择优先，刷新、加载工作流与插件升级均保持偏好。
- 三个模式互斥，在 GuliNodes 顶部工具菜单中用三个按钮切换，ComfyUI 设置提供同源选项。

## 决策

采用单一字符串设置 `GuliNodes.widgetSkin.scope`，取值 `all / own / off`。多个布尔开关会产生「总开关已关闭、第三方开关仍开启」的无效组合，故不采用。

归属判断优先使用节点定义的完整 Python 模块根 `custom_nodes.ComfyUI-GuliNodes` 与 `custom_nodes.ComfyUI-GuliNodes-Dependencies`（支持其子模块），同时兼容 `guli_nodes` 与 `guli_nodes_dependency`。模块信息缺失时才使用 GuliNodes 分类兜底，不按 GG 显示名前缀判断。

范围只改变皮肤。现有行布局、尺寸归属、高度锁、隐藏参数、LoRA 重排与组选择继续生效；参数值、控件序列化、端口及连线均保持。

宿主设置行适配 CSS 与节点皮肤共用范围属性。默认只处理本插件设置行，all 时处理通用设置行，off 时移除适配效果。旧全局内联样式扫描改为范围化 CSS，避免关闭后被观察器重新写回。

## 验收

1. 新装默认 own，本插件与依赖包换肤，官方与其它插件维持原样。
2. all → own → off → all 循环即时生效，已有节点与动态新增控件都正确。
3. off 的标准控件调用原绘制；LoRA 手柄、勾选、组标签保留功能且无胶囊投影。
4. 深浅主题都可读，三个按钮仅一个选中，键盘可操作。
5. 读档后节点尺寸、参数与连线保持；用户保存的 off 优先于开发默认。
6. 运行无头范围断言、真机三档断言、现有全部行布局回归及界面探针。
