## Required contract

- Five ordered inputs: 图像 IMAGE, 人像遮罩 MASK, 处理区域 COMBO[人像,背景] (default人像), 编辑需求 multiline STRING(default''), 全局要求 multiline STRING(default'').
- Five fixed ordered outputs: 图像 IMAGE, 区域遮罩 MASK, 区域请求 STRING, 锁定约束 STRING, 是否编辑 BOOLEAN. Always display all outputs. V3 and legacy wrappers; try importing comfy_api.latest.io at module import, fallback if unavailable.
- Pure helper prepare_region(图像,人像遮罩,处理区域='人像',编辑需求='',全局要求='') returns these five items. Single-image BHWC required; C=3 or4; preserve underlying RGB when stripping alpha (do not composite onto white), no in-place mutations; require image finite and normalized 0–1.
- Whether editing is enabled depends only on 编辑需求.strip(). Empty/whitespace string: return input RGB image, correctly-sized zero MASK, empty request, region fixed constraint, False, without requiring a valid input MASK. Validate invalid image/region even for no-op.
- Active request: accept MASK [H,W], [1,H,W] and [1,1,H,W]; reject batches>1/invalid dimensions, nonfinite, outside0–1, or mismatch. Detect empty black64x64 mask from ordinary LoadImage before generic size error so user gets actionable “请在加载图像的遮罩编辑器涂选人物并保存” advice.
- Human effective area=(M>0.1) pixel-count/total, at least0.002; full-white by this threshold is rejected. Validate HUMAN mask BEFORE background inversion. Current active target (human M or 1-M) area at threshold >0.1 must also be≥0.002, preventing existing GGMaskCrop .002 full-frame fallback. Use exact integer count comparisons at threshold to avoid float32 mean boundary drift. Preserve valid soft weights and return M or1-M, float tensor same image device; do not arbitrarily fill holes or expand mask. Integration decision: also validate human and target effective areas after float32 conversion, because existing GGMaskCrop always casts to float32. Reject with Chinese precision/threshold advice if consumer-normalized area is insufficient; never modify the existing mask module. Exactly0.002 is accepted only when both original and consumer representations remain valid. Returning the original soft weights is retained for final composition.
- Region request includes target name, trimmed user request, optional trimmed 全局要求. Fixed constraint includes keeping original person identity, pose, location, proportion and outer silhouette basically unchanged, same canvas/camera/perspective, excludes editing the other region. For background, person is context not target; for person, background is context not target. All visible strings/errors/tooltips Chinese.
- No new dependency beyond existing torch and standard library; no imports from Goohai/cv2/scipy, no new UI extension. Reuse repo text join helper only if it doesn't force model imports. No changes to mask_tools, image_tools, prompt modules or registries.
