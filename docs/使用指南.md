# 详细使用指南

[返回 README](<../README.md>)；节点速查与最新更新以 README 为准，下文保留操作细节、参数限制与完整借鉴说明，路径以仓库根目录为基准。

## 主要能力

### 画布与前端工具

- **画布交互修复** — ComfyUI 的 DOM 控件定位层（`div[data-testid="dom-widgets"]`）是个 `position: static` 的普通 div，子控件用 `relative + left/top` 定位。节点上的多行文本框一多，这一层就被撑成一大块透明区域盖在画布上（实测某个 57 节点的老工作流被撑到 1600×538），鼠标事件全被它吃掉，表现为**画布拖不动、滚轮不缩放、点节点没反应，但右侧面板和输入框照常能用**。本插件给这一层恢复正确语义：定位层 `pointer-events: none`，其直接子控件 `pointer-events: auto`，画布与输入框各归各位。纯 CSS，不改任何节点数据。
- **工作流排版体检** — `tools/layout_region_edit_workflow.py` 按列对齐重排画布：修节点重叠、收拢散落的预览、重画分组框到真实包围盒、重设打开时的初始视口。只动 `pos` / `size` / `groups` / `extra.ds`，不碰连线与参数，幂等可重复运行；`--check` 只做重叠与悬空引用校验，`--apply` 才写盘并自动备份。
- **顶部工具栏** — 节点/分组上色、取色粘贴、节点尺寸复制粘贴、对齐、等宽等高、自动间距、批量整理。
- **节点标题栏按钮** — 可分别开启「置顶」「节点折叠/恢复」与「输入输出列表隐藏」；图标默认常显，悬停出底，激活态变色。按节点宽度分档收起低频按钮，窄节点仍可从右键菜单操作；状态随工作流持久化。
- **节点端口显示** — 隐藏端口只影响画布显示，不会断开已有连接，切换工作流或重开画布后继续保留。
- **参数按需显示** — 只展示当前选择下真正生效的输入控件，固定输出端口保持稳定；`GG 图像对比 N张` 的图像槽位随连接自动增减，最多 20 张。
- **插件名称显示** — 可自动隐藏节点右上角的插件徽章，选中、点击或悬浮节点时恢复显示。
- **节点控件皮肤** — 顶部工具菜单提供「适配第三方 / 只我们插件 / 所有都关闭」三档。首次安装只统一本插件及配套节点，第三方适配由用户开启，关闭后标准控件恢复宿主外观；开启「适配第三方」后，子图节点及子图内部生成的标准控件也统一使用同一套皮肤。
- **节点外部光效** — 选中节点与正在执行的节点会向外扩散粒子光效，支持 6 种效果、多档强度、效果池与 9 种色彩主题。
- **连线样式** — 颜色、宽度、透明度、发光和流动效果可调，支持 17 种线条样式；显示范围可选全部、选中节点或悬停节点。
- **完成通知** — 工作流成功执行后自动通知本机 TapRelay，默认开启。
- **发送到素言** — 把出图、图像对比与关联提示词推送到素言素材库，默认隐藏，需在设置中开启。
- **标题与分组** — 画布标题/分区标注；分组可新建、改名、四边缩放、整组跳过，也可折叠为同名子工作流小节点。
- **移动对齐吸附** — 拖动节点时自动吸附到邻近节点的边缘，手感接近 PS 移动图层。
- **文本与输入体验** — 文本复制展示、密钥输入、剪贴板导入、模型列表获取、种子生成、整数输入、选项确认、数学表达式、CLIP 文本编码、Qwen Image 2.1 提示词增强、提示词库、文本拼接与打光提示词组合。

### 图像与 Latent

- **基础图像处理** — 尺寸调整（按倍数，或按长边/短边/宽度/高度/宽高直接定尺寸）、裁剪、翻转旋转、亮度/对比度/饱和度/锐化/虚化、色彩校正。
- **图像风格参考** — 使用纯 PyTorch 统计迁移和纹理混合实现，不依赖 OpenCV。
- **图像保存与压缩** — 预览、保存、压缩保存、独立压缩，支持 JPEG/PNG/WEBP。
- **图像对比** — 2 图和最多 20 图拼接预览，适合参数对比和 A/B 测试。
- **图片超分** — Real-CUGAN 的 11 个官方档位（2x / 3x / 4x × 降噪强度），单模型只有 5MB，走 ONNX Runtime 推理；大图自动切 512 块并羽化融合接缝。模型统一放 `models/Real-ESRGAN`，内置档位自动下载，你自己下的 `.onnx` 放进去也能直接选。
- **图像混淆** — 用 4 位密码按 Hilbert 曲线置换图像像素，用于上传前遮挡或还原；V3 会在底部写入宽高条码，缩放后仍能自动识别原尺寸，V2 不改变尺寸且逐像素无损。
- **遮罩裁剪与回贴** — 按遮罩白色区域自动框选、四边扩展后裁剪，输出尺寸支持原像素 / 原像素1:1 / 按边长 / 按K数分辨率 / 按宽高（后三种与 `GG Latent` 共用同一套宽高比例、边长、边长类型、画面方向、分辨率配置）；处理完由 `GG 裁剪恢复` 按接缝把图像羽化贴回原位置，可选颜色还原与背景对照。重绘场景另用 `GG 局部重绘裁剪`：裁之前可对遮罩做低值过滤 / 补洞 / 膨胀 / 反相，四边按宽高各自的比例取上下文，可外扩画布做 outpainting，也可强制成 512/1024 这类采样尺寸。
- **按遮罩合并** — 按遮罩把覆盖图混到背景图上，遮罩可先扩展（膨胀/腐蚀）再羽化，整体强度由透明度控制；覆盖图可缩放到背景尺寸或按原尺寸居中放置，两边张数不同时自动广播。
- **人像 / 背景分区编辑** — [示例工作流](<../examples/workflows/GG-人像背景分区编辑_Qwen2.1_Turbo.json>)人像蒙版默认 SAM3 文本自动识别（也可切手绘），先处理人像、再对结果取反蒙版处理背景，两段串行累加出图；空需求真正跳过对应优化与采样，空/极小/全白人物遮罩报错而不误改整图。每阶段按原遮罩再次限域，保持原坐标、画幅和基本外轮廓；AI 提示词优化可单独开关。**裁剪按原像素保持比例、降噪实测标定为背景 0.6 / 人像 0.35**（低于 0.4 基本看不出变化，旧版 0.45/0.25 加 768 正方形裁剪会把改动稀释到接近直通）。当前版本 **48 节点 / 81 连线**，画布按 7 个分区重新排布（节点零重叠、分组框全包裹、打开即落在输入区），比精简前少 9 个节点、画布高度压缩 62%。详见[使用说明](<../examples/workflows/GG-人像背景分区编辑_使用说明.md>)。
- **Latent 尺寸** — `GG Latent` 支持按边长、按 K 数分辨率、按宽高、按 Latent 接入、按图像接入五种生成方式；按边长用边长与边长类型做自定义尺寸，按 K 数分辨率含 1K–4K 档位，按宽高直接给像素宽高（可接入 `GG 图像宽高` 的宽度/高度输出，自动对齐到 8），另有输入尺寸倍率缩放、图像缩放方法与尺寸读取；另提供 Latent 缩放、VAE 编码/解码缓存。

### 模型、LoRA、采样与视频

- **LoRA** — 20 槽自定义 LoRA 叠加。
- **模型加载** — VAE 缓存编码/解码。
- **采样** — Z-Image 采样器。
- **显存清理** — 卸载 ComfyUI 模型、清理设备缓存、清理 GuliNodes VAE 缓存并输出报告。
- **视频** — 视频加载、路径加载、图像音频合成视频、压缩、保存。

## 节点清单

当前版本共 55 个节点：后端注册 54 个，另有 1 个由前端生成（`GG 选项确认`），完整速查以 [README 节点清单](<../README.md#节点清单>) 为准。

### 图像、尺寸与 Latent

| 节点 | 用途 |
| --- | --- |
| `GG 图像宽高` | 支持按边长、按 K 数分辨率、按 Latent 接入、按图像接入四种方式，输出对齐到 8 的宽度/高度。控件单列排布（标签精简为 `方式` / `比例` / `类型` / `方向` / `倍数`），换方式会自动重排。 |
| `GG Latent` | 支持按边长、按 K 数分辨率、按宽高、按 Latent 接入、按图像接入；按宽高可直接连入像素宽高，输入 Latent/图像时可按倍率调整输出尺寸。 |
| `GG 图像缩放` | 输入 IMAGE 后自动读取宽高。`缩放方式` 选「按倍数」给 `缩放倍率`；选「按长边 / 按短边 / 按宽度 / 按高度」只给那一个目标像素，另一边按原比例推算；选「按宽度高度」则精确给宽高（比例不同会拉伸）。`缩放插值` 对所有方式生效。`整除数` 默认 16，输出宽高就近吸附到它的倍数（填 1000 配 16 会得到 1008，不报错），常用档 0/4/8/16/32/64/128 可直选、其它值走「自定义」、0 表示不对齐。只显示当前方式用得到的参数。 |
| `GG 图像缩放 V2` | 按目标尺寸缩放的完整版：`缩放方法` 可选按长边、按短边（`将边缩放到`）或自定义宽高（宽/高填 0 表示按另一边等比推算）；`缩放模式` 决定内容怎么落进目标框——拉伸、裁剪、按自定义颜色填充、按边框主色填充、按边缘像素填充、按总像素等比；`固定方向` 决定裁剪或填充时保留哪一侧，`整除数` 把输出宽高就近对齐到 8/16/64 这类倍数，`执行条件` 可设「只缩不放」「只放不缩」。遮罩随图像同步缩放，另输出实际宽度/高度。只显示当前选择下真正生效的参数。 |
| `GG 尺寸适配` | 按输入图像比例、常见训练比例和目标面积，选择宽高均为 32 倍数的 Qwen-Image 2.1 稳定尺寸，并模拟内部缩放检查固定点；支持 `default` 自动分辨率、512~2048 手动档、容差比例，以及裁剪 / 补边 / 拉伸三种输出模式，输出图像、实际宽度、实际高度和分辨率。补边颜色只在「补边」模式显示。 |
| `GG 纯色图像` | 给 `宽度`、`高度` 和 `填充颜色`，直接生成一张纯色图（单输出 IMAGE）。作画布底、外扩填充色、合成垫底用；单边上限 8192 像素，超了给中文提示而不是把显存吃满。`宽度` 与 `高度` 同行，`填充颜色` 独占一行（颜色控件要同时画标签、色值和色块，挤成一列会互相压住）。点颜色控件弹出输入框，可直接敲 `#RRGGBB` / `#RGB` / `r,g,b`，也能调取色器；填错不落盘、输入框标红。 |
| `GG VAE解码` | 加载并缓存 VAE 后解码 Latent。 |

### 图像处理与输出

| 节点 | 用途 |
| --- | --- |
| `GG 图像裁剪` | 中心、坐标、比例等裁剪。 |
| `GG 分区编辑准备` | 检查单张图像和手绘人像遮罩，输出人像或背景区域遮罩、区域请求、固定姿态/位置/外轮廓约束和「是否编辑」；编辑需求为空或只有空白时返回原图、空请求与假，不要求有效遮罩。启用编辑时拒绝无效尺寸、NaN/Inf、越界数值、空/极小/全白人像与极小目标区域，防止下游裁剪误退化为整图。 |
| `GG 遮罩裁剪` | 按遮罩白色区域自动框选、四边扩展后裁剪，输出 `接缝` / `裁剪图像` / `裁剪遮罩`。`扩展方式` 可选四边统一或分别设置（只显示对应的系数）；`输出尺寸` 决定 `裁剪图像` 与 `裁剪遮罩` 的宽高（两者始终同尺寸），可选原像素、原像素1:1、按边长、按K数分辨率、按宽高，只显示当前方式用得到的参数。遮罩白色区域小于整图 0.2% 时退化为整图裁剪。 |
| `GG 裁剪恢复` | 按 `接缝` 把处理后的裁剪图像羽化贴回原图位置，可调遮罩扩展、遮罩羽化与颜色还原强度；可另接 `裁剪遮罩` 指定贴回区域、接 `背景图像` 做对照输出。接 `GG 局部重绘裁剪` 的接缝时还能把外扩出来的画布一起贴出来。 |
| `GG 局部重绘裁剪` | 重绘向的裁剪：裁之前按「低值过滤 → 遮罩填充 → 遮罩扩展 → 遮罩反相」处理遮罩，`上下文扩展` 按宽高各自的比例带上下文（1.0 紧贴遮罩、2.0 每边多一倍），`画面外扩` 四边各扩出 N 像素新画布做 outpainting（新区域用最外圈像素延展并标记为重绘），`输出宽度` / `输出高度` 强制采样尺寸（都为 0 时按上下文本身大小输出），`尺寸对齐` 向上取整到 8 的倍数。输出 `接缝` / `裁剪图像` / `裁剪遮罩`，采样完接 `GG 裁剪恢复` 贴回。可另接 `上下文遮罩` 把别的区域一起保留进画面。 |
| `GG 图像合并（遮罩）` | 按 `遮罩` 把 `覆盖图` 混到 `背景图` 上：`遮罩扩展` 正数膨胀、负数腐蚀，`模糊半径` 羽化边缘，`透明度` 控整体强度；`匹配图像大小` 开启时把覆盖图缩放到背景尺寸，关闭时按原尺寸居中放置。不接 `遮罩` 时整图按透明度叠加，此时 `遮罩扩展` / `模糊半径` 自动隐藏。两边张数不同时，只有 1 张的那边自动复用。 |
| `GG 图像变换` | 水平/垂直翻转和 90/180/270 度旋转。 |
| `GG 图像调整` | 亮度、对比度、饱和度、锐化和虚化。 |
| `GG 色彩校正` | 使用 torch 张量批量调整温度、色调、明度、对比度、饱和度和伽马。 |
| `GG 颜色校准` | 对比原始图像与编辑图像，在未变化区域估计逐通道颜色/对比度校准；可自动生成变化遮罩，也可接入手动遮罩，输出校准图像、变化遮罩和变化比例。 |
| `GG 图片超分（Real-CUGAN）` | 用 Real-CUGAN 的 ONNX 模型做 2x / 3x / 4x 超分，`模型` 一栏把倍率与降噪强度合在 11 个官方档位里。大图按 512 块切分推理、重叠区羽化融合，`分块重叠` 控制接缝平滑度（0 会有网格，32~64 基本看不出）；`设备` 自动挑选显卡后端，没有就回落 CPU；`自动下载` 关闭后只用本地已有模型；`超分后卸载` 默认开启，跑完把模型占用的内存/显存还回去（关掉则复用缓存会话，连续多轮更快）。模型下拉框会自动收录 `ComfyUI/models/Real-ESRGAN/` 里你自己放的 `.onnx`（按模型结构判断倍率，不看文件名），刷新页面即生效。输出单个 IMAGE，支持批量，RGBA 的 alpha 一起放大。 |
| `GG 风格参考` | 参考图像风格统计迁移和纹理混合。 |
| `GG 图像加载` | 在节点内选择、粘贴或上传图像，输出 `图像` 与 `遮罩`；遮罩优先读取手动选择文件，其次同名 sidecar，再读取图像 Alpha，均无则输出全零遮罩。支持裁剪、自动预览与尺寸显示。 |
| `GG 图像保存` | 保存图像。 |
| `GG 图像压缩保存` | 压缩并保存图像；保存后清理模型、设备缓存、Python GC 和 GuliNodes VAE 缓存默认开启。 |
| `GG 图像压缩` | 输出压缩后的图像。 |
| `GG 图像对比 2张` | 双图对比预览。 |
| `GG 图像对比 N张` | 默认一个图像输入，连接后自动增加下一个，最多 20 张；标签只显示已连接图像源，断开后自动收起。 |
| `GG 图像混淆` | 按 4 位密码置换或还原图像像素。V3 在底部写入宽高条码，缩放后仍可自动识别原尺寸并解码；V2 不改变尺寸且逐像素无损，但缩放后无法还原。 |

### 文本、输入与工作流组织

| 节点 | 用途 |
| --- | --- |
| `GG 文本` | 显示文本并支持前端复制。 |
| `GG TXT加载` | 像加载图像一样选择或上传 TXT/MD 文本文件，并输出文本内容。 |
| `GG 文本拼接` | 把最多 20 段文本按顺序拼成一段：默认用「换行 + 空白行」分隔，填了自定义分隔符时让它单独占一行、上下各留一个空白行，空段自动跳过。默认只显示一个文本框，填上字就自动长出下一个（最多 20 个），**槽位被转成输入端口并接线也算在用**，接完线立刻长出下一个空框；清空某个框只清它自己，下面的内容绝不往前搬，节点高度随可见槽位贴合。 |
| `GG 提示词库` | 在文本框下方列出可点击的预设，点一下就追加进 `提示词`（多个预设自动换行、再点同一条取消）。预设按分类分组、分类可整行点击收起、每条带自己的颜色，可新增 / 编辑 / 删除，**编辑与删除按钮只在鼠标移上去时显示**，双击卡片也能编辑；预设存在 `user/default/gg-prompt-library.json`，跨工作流共享，至少保留一条。 |
| `GG CLIP文本` | 加载 CLIP 并编码文本。 |
| `GG 密钥输入` | 用于 API Key、令牌、API 端点和模型名称，可测试当前配置、按端点和密钥获取模型列表并确认选择；支持单字段粘贴和一次导入端点/API Key/模型，能够识别 JSON、curl、带标签文本并自动提取与适配端点网址；同时输出兼容 JSON `API配置`，以及可分别连接下游 `api_key`、`api_base_url`、`model` 的独立字符串端口。 |

## 常见问题

### 安装时还需要 `pip install -r requirements.txt` 吗？

可以执行，但当前文件不安装额外包，只用于兼容 ComfyUI Manager 或已有安装习惯。

### 视频加载或压缩失败怎么办？

确认 `ffmpeg` 可以在系统 PATH 中直接运行。大视频可以使用 `GG 视频路径加载` 直接选择本机文件路径，避免浏览器上传大小限制；也可以放入 `ComfyUI/input` 后在节点里选择。

### 网页 AI 节点无法嵌入？

部分平台会限制 iframe 嵌入。可以尝试自定义移动端地址，或在外部浏览器打开平台网页使用。

### TapRelay 没有收到 ComfyUI 完成通知？

确认 TapRelay PC 软件正在运行并监听 `1122` 端口，然后在 ComfyUI 设置的 `GuliNodes / TapRelay` 中，或点击顶部铃铛按钮，确认“ComfyUI 完成后通知 TapRelay”已开启。通知由 GuliNodes 后端转发到 `http://127.0.0.1:1122/send`，TapRelay 不可用时不会阻断工作流。

### `GG 镜头打光提示词` 选中的光效一定生效吗？

不一定。这些文字是**提示**而不是**控制**，实际效果取决于下游模型的训练数据。按常见响应情况大致分三档：

| 档位 | 光效 / 机位 | 说明 |
| --- | --- | --- |
| 基本都会照做（29 种） | 镜头光晕、丁达尔光、窗光、白底棚拍、柔光箱、平光、高调光、低调光、环形灯、机顶闪、逆光剪影、光帐篷、阴天散射、蓝调时刻、正午硬光、串灯虚化、雨夜霓虹、烛光、屏幕光、水下光、闪电、轮廓光、日落金光、冷暖双色、霓虹双色、戏剧聚光、月光、火光、硬光切割；机位里的荷兰角、过肩镜头、镜中视角 | 都是摄影 / 图库 caption 里的高频说法，SD1.5 起就能稳定响应 |
| 通常会有效、细节不保证（24 种） | 树荫光、条纹光、透明焦散、夜间开灯、双柔光箱、渐变背景、硬光硬影、镜面台面、透光背光、玻璃勾边、彩色勾边、晨雾散射、暴风雨光、雪地反光、车窗光、门缝光、分色背景、舞台追光、水波光影、彩色投影、窗框投影、投影画面、棱镜虹光、高光溢出；机位里的前景遮挡 | 光效形态（叶影位置、条带数量、光斑形状、倒影角度）由模型自由发挥 |
| 依赖模型能力（19 种） | 伦勃朗光、蝴蝶光、环形光、分割光、窄面光、宽面光、蚌壳光、雷达罩、侧逆光、发丝光、分离光、顶光、反光板、金色反光板、底光、顶光平铺、无缝聚光、白上白、黑上黑；机位里的 3/4、侧脸、背影、倾斜仰拍 / 倾斜俯拍 | 属于摄影术语；Flux / Qwen 一类长文本模型更准，SD1.5 / SDXL 常退化成「侧光 / 强对比」 |

另外三点：

- **模型差异**：SD1.5 / SDXL 的 CLIP 上限是 77 token（约 60 个英文词），超出后会分块编码、后半段被稀释。面板「最终提示词」右侧会显示当前词数，超过阈值时变橙色并带说明。节点输出固定英文（面板仍是中文），所以这个阈值直接对着英文词算；Flux / SD3.5 / Qwen-Image / Z-Image 对长句更友好，超一点也不至于全丢。
- **叠加越多越互相稀释**：一次 2–3 个光效最稳；色温相反的组合（例如「月光」+「日落金光」）会被模型折中，结果不可控。
- **要精确控光，靠文字不够**：需要 IC-Light 一类打光模型、参考图或 ControlNet 做条件输入。这个节点做的是把想法快速写成模型看得懂的描述，不能替代光照控制模型。

### `GG 提示词增强qwen2.1` 报「连接在传输过程中被本机网络软件中断」？

这是本机到 API 之间的 HTTPS 连接被掐断（Windows 报 10053/10054），不是节点或接口地址的问题。节点会自动重试 3 次（含一次绕开系统代理的直连尝试），仍失败时按错误提示检查代理/VPN 客户端、安全软件，或换一条网络线路；控制台会打印每次重试的原因。

### `GG 提示词增强qwen2.1` 本地LLM 很慢，或者输出里全是「Thinking Process / 思考过程」？

先看控制台的 `[GG 本地LLM] 推理后端：…`，再看生成用时与 token 数：

- **后端只有 CPU，没有 CUDA / 其它 GPU 后端** → 即使设置了 `n_gpu_layers=-1`，也仍是 CPU 推理。Windows 独立 worker 现已自动登记当前解释器中已有的 PyTorch / NVIDIA / CUDA 运行库目录，同时补齐原生 DLL 搜索路径；只借用 DLL，不导入 torch、不修改 ComfyUI 宿主的环境。仍显示 CPU 时，核对安装的是与平台匹配的 GPU 版 `llama-cpp-python`。RPC offload 能力不代表有 GPU。
- **已有 CUDA 后端但显存吃紧** → 模型与视觉投影还需要足够的空闲显存。连续改提示词可以选「保持加载」复用模型；要给后续生图腾显存则保留「自动」或「运行后自动卸载」。运行前已有其它大模型时可选「运行前后自动卸载」。
- **文生图仍在写英文分析、输出语言选中文却出英文** → 说明模型用的是自带聊天模板，思考没关。现在文生图会自动借用与主模型配套的 `mmproj` 构造 Qwen 聊天模板并关闭思考（`mmproj` 不参与编码、也不上 GPU）；控制台会打印「文生图已关闭思考」。找不到配套 `mmproj` 时会退回模型自带模板，耗时与语言效果都会差一些。
- **生成 token 正好等于上限（1536）** → 这表示输出预算触顶，需检查正文是否完整；长描述和未结束的计划都可能触顶，不能只凭计数判断模型在思考。节点保留官方规则、末位正文约束和既有解析；本次 GPU 修复未通过缩短提示词、压缩参考图或降低输出上限换速度。
- 首次加载、重复执行、生成 token 数与图像编码都会影响耗时。控制台的「生成完成」不含加载与卸载；画布上的节点耗时与任务历史里的整条工作流耗时也不是同一口径。早前本地LLM 的 300–490 秒样本包含未正确加载 CUDA 的情况，不再作为正常 GPU 推理的参考值。
- 本机 RTX 4060 Ti 16GB / Qwen-Image-2.1-PE Q5_K_S 验证：同输入、同种子、同采样参数的 64-token 生成从 17.44 秒降至 2.15 秒（约 8.1 倍）；加载单列为 1.75 / 5.86 秒。关闭思考后文生图实测约 15 秒（此前 38 秒，模型把约 1300 token 花在英文分析上）；单图编辑 16.6 秒、单图反推 15.2 秒，按服务端执行事件计时、不含排队。它们是单机样本，不是固定时限。
